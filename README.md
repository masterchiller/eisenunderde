# Müller Eisen & Erde GmbH – Website

Statische Website (eine Datei: `index.html`). Domain: www.eisenunderde.ch

## Veröffentlichen mit GitHub Pages
1. Neues Repository auf github.com anlegen, `index.html`, `CNAME` und `README.md` hochladen.
2. Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
3. Beim Domain-Anbieter: CNAME-Eintrag `www` → `DEIN-BENUTZERNAME.github.io`.
4. In Pages "Enforce HTTPS" aktivieren.
